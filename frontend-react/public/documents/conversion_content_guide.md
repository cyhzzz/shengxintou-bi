# 内容平台加微链路导入指南

## 数据来源
由省心投业务系统 **企微链路导出工具** 生成（链路追踪 → 导出明细）。

## 适用场景
- 内容平台（抖音 / 腾讯 / 小红书 / 快手）每日的 **加微链路明细**
- 1 行 = 1 个客户线索到企微添加的归因链路

## 字段映射（业务系统列 → 平台字段）

| 业务系统导出列 | 平台表字段 | 说明 |
| --- | --- | --- |
| 客户线索ID | `fact_conv_content.客户线索ID` | 唯一线索号 |
| 客户来源 | `fact_conv_content.客户来源` | 含 [平台]引流-[主播名字] 模式 |
| 创作者 | `fact_conv_content.创作者` | 笔记 / 视频创作者 |
| 广告策略 | `fact_conv_content.广告策略` | 投教 / 品宣 / 开户权益 等 |
| 客户昵称 | `fact_conv_content.客户昵称` | 微信昵称 |
| 加微时间 | `fact_conv_content.加微时间` | ISO 时间戳 |
| 开户时间 | `fact_conv_content.开户时间` | ISO 时间戳 |
| 入金时间 | `fact_conv_content.入金时间` | ISO 时间戳 |
| 有效户标记 | `fact_conv_content.有效户` | 1=是 0=否 |

## 操作步骤
1. 业务系统「链路追踪 → 内容平台」勾选导出日期
2. 导出明细 Excel，文件名形如 `内容平台加微链路_20260601_20260630.xlsx`
3. 在省心投 BI 「系统配置 → 数据导入」选择 **内容平台加微链路**
4. 拖入文件并确认导入

## 注意事项
- 单次导入不超过 50 万行
- 同一客户线索号覆盖更新
