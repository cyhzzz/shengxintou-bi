﻿# 开户渠道分析导入指南

## 数据来源
由省心投业务系统 **开户日报导出工具** 生成（开户管理 → 数据导出）。

## 适用场景
- 非广告渠道（互联网引流 / 合作机构 / 员工开户 / 自然流入）的每日开户汇总
- 用于全渠道获客报表的核心数据源

## 字段映射（业务系统列 → 平台字段）

| 业务系统导出列 | 平台表字段 | 说明 |
| --- | --- | --- |
| 日期 | `agg_daily_channel_open.日期` | yyyy-MM-dd |
| 渠道类别 | `agg_daily_channel_open.渠道类别` | 互联网引流 / 合作机构 / 员工开户 / 自然流入 |
| 渠道名称 | `agg_daily_channel_open.渠道名称` | 子渠道名 |
| 开户成功 | `agg_daily_channel_open.开户成功` | 整数 |
| 入金 | `agg_daily_channel_open.入金` | 整数 |
| 有效户 | `agg_daily_channel_open.有效户` | 整数 |

## 操作步骤
1. 业务系统「开户管理 → 数据导出」勾选日期区间
2. 导出 Excel，文件名形如 `开户日报_20260601_20260630.xlsx`
3. 在省心投 BI 「系统配置 → 数据导入」选择 **开户渠道分析**
4. 拖入文件并确认导入

## 注意事项
- 同一 (日期, 渠道类别, 渠道名称) 覆盖更新
- 单次导入不超过 30 万行
