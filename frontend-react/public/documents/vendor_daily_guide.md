﻿# 厂商广告投放分析导入指南

## 数据来源
由省心投业务系统 **厂商投放报表导出** 生成（厂商分析 → 数据导出）。

## 适用场景
- 每日 × 平台 × 厂商 × 业务模式 的统一漏斗超集
- 用于厂商分析、转化漏斗、应用市场子报表等

## 字段映射（业务系统列 → 平台字段）

| 业务系统导出列 | 平台表字段 | 说明 |
| --- | --- | --- |
| 日期 | `agg_vendor_daily.日期` | yyyy-MM-dd |
| 平台 | `agg_vendor_daily.平台` | 抖音/腾讯/小红书/快手... |
| 厂商 | `agg_vendor_daily.厂商` | 代理商全称 |
| 业务模式 | `agg_vendor_daily.业务模式` | 直播/信息流/应用市场 |
| 渠道类别 | `agg_vendor_daily.渠道类别` | 互联网引流/合作机构 等 |
| 花费 | `agg_vendor_daily.花费` | 元 |
| 展现量 | `agg_vendor_daily.展现量` | 整数 |
| 点击量 | `agg_vendor_daily.点击量` | 整数 |
| 线索量 | `agg_vendor_daily.线索量` | 整数 |
| 开户量 | `agg_vendor_daily.开户量` | 整数 |
| 入金量 | `agg_vendor_daily.入金量` | 整数 |
| 有效户 | `agg_vendor_daily.有效户` | 整数 |

## 操作步骤
1. 业务系统「厂商分析 → 数据导出」勾选日期区间
2. 导出 Excel，文件名形如 `厂商投放_20260601_20260630.xlsx`
3. 在省心投 BI 「系统配置 → 数据导入」选择 **厂商广告投放分析**
4. 拖入文件并确认导入

## 注意事项
- 同一 (日期, 平台, 厂商, 业务模式) 覆盖更新
- 单次导入不超过 50 万行
