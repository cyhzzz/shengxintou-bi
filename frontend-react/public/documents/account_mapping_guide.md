> **投放账号映射**，数据源为省心投平台的 **账号信息表**（单层广告账号 ID 体系）。

# 投放账号映射导入指南

## 数据来源

由省心投业务系统 **运营管理后台** 导出（账号管理 → 导出 → 选择 Excel）。

## 适用场景

- 每月新增账号后，补齐账号 → 代理商 → 业务模式 的归属关系。

- 厂商/渠道拆分前，账号名称归一化准备。

## 当前账号结构

> 业务已由「主账号 + 子账号」两层账号收敛为**单层广告账号 ID 体系**：每个平台账号即一个广告账号，不再区分主/子账号。旧两层结构的历史文件仍可导入（主账号两个字段留空兼容）。

## 字段映射（业务系统导出列 → 平台表字段）

| 业务系统导出列 | 平台表字段                          | 说明                      |
| ------- | ------------------------------ | ----------------------- |
| 序号      | `dim_account.序号`               | 行序号，导入时自动生成             |
| 平台      | `dim_account.platform`         | 抖音 / 腾讯 / 小红书 / 应用市场 等  |
| 子账号ID   | `dim_account.sub_account_id`   | **单层广告账号 ID**（当前唯一账号维度） |
| 子账号名称   | `dim_account.sub_account_name` | **单层广告账号名称**            |
| 代理商名称   | `dim_account.agency_name`      | 代理商全称                   |
| 代理商简称   | `dim_account.agency_short`     | 代理商简称/显示名               |
| 代理商字母简称 | `dim_account.agency_letter`    | 代理商字母简称                 |
| 业务模式    | `dim_account.business_model`   | 直播 / 信息流 / 应用市场 等       |

> 兼容字段：旧两层结构的「主账号ID / 主账号名称」（`dim_account.main_account_id / main_account_name`）已不再导出；新文件不含这些列，导入后自动留空，不影响账号归属与报表。

## 操作步骤

1. 业务系统「运营管理后台 → 账号管理」选择导出时间范围。
2. 点击「导出 Excel」按钮，生成文件（如 `账号信息表.xlsx`）。
3. 在省心投 BI 「系统配置 → 数据导入」选择 **投放账号映射**。
4. 拖入文件，默认开启「覆盖模式」。
5. 导入完成后会自动刷新账号归属，所有报表立即生效。

## 注意事项

- 不要手动修改 Excel 表头（表头需与上表一致）。

- 同一账号在 Excel 内不允许重复。

- 同一 (账号, 平台) 在已有数据库中只能对应一条记录。
