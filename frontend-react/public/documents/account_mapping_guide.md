﻿# 投放账号映射导入指南

## 数据来源
由省心投业务系统 **运营管理后台** 导出（账号管理 → 导出 → 选择 Excel）。

## 适用场景
- 每月新增账号后，需要补齐账号 → 代理商 → 业务模式 的归属关系
- 厂商/渠道拆分前，账号名称归一化准备

## 字段映射（业务系统列 → 平台字段）

| 业务系统导出列 | 平台表字段 | 说明 |
| --- | --- | --- |
| 投放账号 | `dim_account.account_name` | 账号名称 |
| 平台 | `dim_account.platform` | 抖音 / 腾讯 / 小红书 / 应用市场... |
| 代理商 | `dim_vendor.vendor_name` | 代理商全称 |
| 业务模式 | `dim_vendor.business_model` | 直播 / 信息流 / 应用市场 |
| 渠道类别 | `dim_account.channel_category` | 互联网引流 / 自然流入 等 |

## 操作步骤
1. 业务系统「运营管理后台 → 账号管理」选择导出时间范围
2. 点击「导出 Excel」按钮，生成的文件名形如 `账号映射_2026Q2.xlsx`
3. 在省心投 BI 「系统配置 → 数据导入」选择 **投放账号映射**
4. 拖入文件，默认开启「覆盖模式」
5. 导入完成后会自动刷新账号归属，所有报表立即生效

## 注意事项
- 不要手动修改 Excel 表头
- 同一账号在 Excel 内不允许重复
- 同一 (账号, 平台) 在已有数据库中只能对应一条记录
