# 厂商广告计划维度明细（9.3）上传指南

本表为**应用市场广告计划维度的投放日明细**（日 × 计划 × 关键词粒度），用于「应用市场 · 广告计划分析」报表，
提供**计划级**的消耗 / 展示 / 点击 / 下载指标；`计划ID` 与「应用市场计划分解」表的 `广告分组ID` 关联。

> 导入方式：**原样覆盖写入**（replace），不做任何中间计算。表头固定，后续只更新内容。

## 一、支持的 Excel 结构

单 Sheet，表头如下（顺序不强制，按列名匹配）：

| 列名 | 说明 | 落库类型 | 备注 |
| --- | --- | --- | --- |
| 日期 | 投放日期 | Text | `YYYY-MM-DD` |
| 平台 | 所属应用市场 | Text | 源表可能为 `OPPO`/`VIVO` 大写，落库统一转小写 `oppo`/`vivo` |
| 厂商名称 | 投放厂商 | Text | |
| 业务模式 | 业务模式 | Text | 如 `APP下载` |
| 计划ID | 广告计划唯一 ID | BigInteger | 关联「应用市场计划分解」`广告分组ID`；超长 ID 自动转字符串 |
| 计划名称 | 计划名称 | Text | |
| 关键词ID | 关键词唯一 ID | BigInteger | 超长 ID 自动转字符串 |
| 关键词名称 | 关键词名称 | Text | |
| 展示量 | 展示次数 | BigInteger | |
| 点击量 | 点击次数 | BigInteger | |
| 下载量 | 下载次数 | BigInteger | |
| 花费 | 消耗金额 | Float | |

## 二、导入规则

1. **平台归一**：`OPPO`→`oppo`、`VIVO`→`vivo`。
2. **仅保留 7 大应用市场**：`oppo` / `vivo` / `荣耀` / `小米` / `华为` / `鸿蒙` / `苹果`，
   其余平台的行将被丢弃（防御性过滤，保证与下载链路口径统一）。
3. **日期归一**：`日期` 统一为 `YYYY-MM-DD`。
4. **覆盖写入**：每次上传替换整表，不保留历史（如需历史版本请另存文件）。
5. **主键**：`id` 由系统自增，无需在 Excel 中提供。
