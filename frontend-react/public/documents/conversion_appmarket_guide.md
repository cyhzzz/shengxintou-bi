﻿# 应用市场下载链路导入指南

## 数据来源
由省心投业务系统 **应用市场归因导出** 生成（应用市场 → 归因明细）。

## 适用场景
- 小米 / 华为 / OPPO / VIVO / 荣耀 / 苹果 商店的 **下载 → 开户 归因明细**
- 1 行 = 1 个设备号的下载激活链路

## 字段映射（业务系统列 → 平台字段）

| 业务系统导出列 | 平台表字段 | 说明 |
| --- | --- | --- |
| 设备号 | `fact_conv_appmarket.设备号` | OAID / IDFA 等 |
| 资金账号 | `fact_conv_appmarket.资金账号` | 客户开户后回传 |
| 应用市场 | `fact_conv_appmarket.应用市场` | 小米/华为/OPPO/VIVO/荣耀/苹果 |
| 渠道类型 | `fact_conv_appmarket.渠道类型` | 信息流/搜索/商店推荐 等 |
| 下载日期 | `fact_conv_appmarket.下载日期` | yyyy-MM-dd |
| 激活APP | `fact_conv_appmarket.激活APP` | 1=是 0=否 |
| 开户成功 | `fact_conv_appmarket.开户成功` | 1=是 0=否 |
| 入金 | `fact_conv_appmarket.入金` | 1=是 0=否 |
| 有效户 | `fact_conv_appmarket.有效户` | 1=是 0=否 |

## 操作步骤
1. 业务系统「应用市场 → 归因明细」勾选导出日期
2. 导出 Excel，文件名形如 `应用市场归因_20260601_20260630.xlsx`
3. 在省心投 BI 「系统配置 → 数据导入」选择 **应用市场下载链路**
4. 拖入文件并确认导入

## 注意事项
- 同一设备号覆盖更新
- 单次导入不超过 100 万行
