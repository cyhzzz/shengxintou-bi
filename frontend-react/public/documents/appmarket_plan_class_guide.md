# 应用市场计划分解（广告计划分类表）上传指南

本表为**应用市场广告计划分类维度**，用于后续「应用市场计划分解」分析：把每个广告分组按
应用市场、版位、子版位、出价方式归类，再关联应用市场下载链路（fact_conv_appmarket.广告计划ID）
拆解各分组 / 版位的获客贡献。

> 导入方式：**原样覆盖写入**（replace），不做任何中间计算。表头固定，后续只更新内容。

## 一、支持的 Excel 结构

单 Sheet，表头如下（顺序不强制，按列名匹配）：

| 列名 | 说明 | 落库类型 | 备注 |
| --- | --- | --- | --- |
| 应用市场 | 所属应用市场 | Text | 源表可能为 `OPPO`/`VIVO` 大写，落库统一转小写 `oppo`/`vivo` |
| 广告分组ID | 广告分组唯一 ID | BigInteger | 关联下载链路 `广告计划ID`；超长 ID 自动转字符串 |
| 广告分组名称 | 分组名称 | Text | |
| 版位 | 投放版位 | Text | 如 搜索 / 推荐 / 展示优选 等 |
| 子版位 | 子版位 | Text | 如 品牌词 / 行业词 / 竞品词 等 |
| 出价 | 出价方式 | Text | 如 ocpd付费 / 开始开户 / CPD 等 |

## 二、导入规则

1. **应用市场归一**：`OPPO`→`oppo`、`VIVO`→`vivo`，与其余中文市场保持一致。
2. **仅保留 7 大应用市场**：`oppo` / `vivo` / `荣耀` / `小米` / `华为` / `鸿蒙` / `苹果`，
   其余应用市场的行将被丢弃（防御性过滤，保证后续分析口径统一）。
3. **覆盖写入**：每次上传替换整表，不保留历史（如需历史版本请另存文件）。
4. **主键**：`id` 由系统自增，无需在 Excel 中提供。
