﻿# 小红书笔记导入指南

## 数据来源
由省心投业务系统 **小红书笔记导出工具** 生成（小红书笔记 → 导出明细）。

## 适用场景
- 小红书笔记级数据 + 笔记聚合
- 用于小红书笔记列表、小红书运营分析、运营周报等

## 字段映射（业务系统列 → 平台字段）

| 业务系统导出列 | 平台表字段 | 说明 |
| --- | --- | --- |
| 笔记ID | `agg_xhs_note.笔记ID` | 小红书原始 ID |
| 笔记标题 | `agg_xhs_note.笔记标题` | |
| 笔记类型 | `agg_xhs_note.笔记类型` | 视频 / 图文 |
| 内容类型 | `agg_xhs_note.内容类型` | 图文笔记 / 视频笔记 |
| 笔记账号 | `agg_xhs_note.笔记账号` | 发布账号名称 |
| 创作者 | `agg_xhs_note.创作者` | 笔记 / 视频作者 |
| 广告策略 | `agg_xhs_note.广告策略` | 投教 / 品宣 / 开户权益 等 |
| 发布时间 | `agg_xhs_note.发布时间` | yyyy-MM-dd HH:mm:ss |
| 总展现量 / 点击量 / 互动量 / 消费金额 | `agg_xhs_note.总展现量/总点击量/总互动量/消费金额` | |
| 推广展现 / 点击 / 互动 | `agg_xhs_note.推广展现量/推广点击量/推广互动量` | |
| 私信进线 / 添加企微 / 开户人数 | `agg_xhs_note.私信进线人数/添加企微人数/开户人数` | |

## 操作步骤
1. 业务系统「小红书笔记 → 导出明细」勾选日期区间
2. 导出 Excel（**系统会自动丢弃 `Unnamed: 24` 等脏列**）
3. 在省心投 BI 「系统配置 → 数据导入」选择 **小红书笔记**
4. 拖入文件并确认导入

## 注意事项
- 同一笔记 ID 覆盖更新
- 单次导入不超过 20 万行
